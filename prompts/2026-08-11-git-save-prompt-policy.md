# Commit policy requested

For future Proms-Lister changes:

1. Use a concise summary of the user's prompt as the Git commit message.
2. Store the user's prompt in the repository as part of the Git save so the request associated with each change is preserved in Git history.
3. Where a change includes multiple requested items, the commit message should summarise the complete request rather than use a generic message such as "fix" or "update".
